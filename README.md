# Xreoct

Xreoct is a custom language and game project built around its own file formats and runtime ideas.

## Project Structure

- `game/splash/` - Splash screens, animations, and offline startup.
- `game/startscreen/` - Main start screen, language settings, and game entry.
- `.rsx` - Xreoct source files used for screens, components, and game logic.
- `.rs` - Xreoct module and system files.

## Current Features

- Animated splash screen
- Offline mode screen
- Start screen
- Language zones
- Game version display
- Configuration button
- Play button and loading route
- Modular exports

## Status

Xreoct is currently in development. More systems, screens, and game features will be added over time.
